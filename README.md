# Road to Glory Roblox

Story-driven football career game for Roblox, inspired by the feeling of a cinematic player career while using original characters, clubs, storylines and systems.

## V0.1 goal

Create a player, enter a prototype training pitch, control the ball, shoot/pass/dribble, score goals, see a match clock and manager rating, and provide the technical foundation for the Academy Trial career chapter.

## Stack

- Roblox Studio
- Luau
- Rojo project structure
- GitHub source control

See `docs/ROADMAP.md` for the staged build plan and `docs/SETUP.md` for local setup.
