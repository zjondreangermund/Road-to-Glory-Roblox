# Local Setup

## Requirements
- Roblox Studio
- Rojo
- Git

## First run
1. Clone this repository.
2. Open Roblox Studio and create/open a blank place.
3. From the repository folder run `rojo serve`.
4. Connect the Rojo Studio plugin to the running project.
5. Sync the project into Studio.
6. Press Play.

The current build creates the prototype pitch, boundaries, goals, football and expanded Academy Training course at runtime.

## Controls
- E: Shoot
- Q: Pass
- F: Toggle dribble
- T: Start/restart Academy Training
- Mobile: SHOOT, PASS, DRIBBLE and TRAINING touch buttons are created automatically.

## Academy Training V0.2 Expanded
Press T to begin the five-drill assessment:
1. Sprint through the yellow start/finish markers.
2. Complete the purple agility slalom in order.
3. Hit all five red shooting targets.
4. Pass through all five blue passing gates.
5. Dribble through all ten orange gates in order.

A live training score is shown during the assessment. Finishing all five drills generates a Scout Report containing pace, agility, shooting, passing and dribbling scores plus an overall grade.

During training, normal match goal resets are suppressed so drill attempts are not interrupted.
